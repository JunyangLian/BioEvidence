# BioEvidence 项目总览（v1 → v2 → v3）

**一页定位**：面向求职/展示的项目说明。所有数字均可从列出的冻结产物复算；
**不同版本、模型、任务、数据集、证据条件的分数分开列出，不放在同一排名里**。
更新：2026-10-01（v3-P1 探索性结项）。

---

## 1. 问题

生物医学文献证据问答（PubMedQA 风格）：给定**问题**与若干**结构式摘要证据片段**
（带章节标签：BACKGROUND / METHODS / RESULTS …），系统需输出严格四行契约：

```
Label: yes | no | maybe        ← 证据指向的结论方向
Reason: <一句基于证据的话>
Citations: E1, E3              ← 必须来自所给证据；弃答时应为 None
Answerable: yes | no           ← 所给证据本身是否足以回答（弃答机制）
```

核心难点不是"答对"，而是**回答的每句话都要能回溯到所给证据**，且**证据不足时要诚实弃答**。

## 2. 系统架构（v1 主线，v3 复用其契约与证据构造）

```
PubMedQA 语料（1000 篇结构式摘要 → 3,358 个章节 chunk）
   │
   ├─ 检索：BM25（k=10）→ section-aware 重排 / Results 配额（A2：m=3，quota=1）
   │        ↓ 冻结配置 configs/retrieval_section.yaml
   ├─ 证据块：按 section_index 降序填充至 900 token，渲染 [E1] (章节) 原文
   │        ↓
   ├─ 模型：v1 = Qwen3-0.6B + LoRA（adapter p6-taskb-lora，4bit 量化训练）
   │        v3 = Ternary Bonsai 2 27B（三值量化 GGUF，llama.cpp 本地推理，**冻结不微调**）
   │        ↓ 提示 = v1 四行契约（v3 逐字沿用，指纹 ff7103c06b3760c3）
   └─ 解析：严格正则（Label/Reason/Citations/Answerable），
            三级判定 ok / invalid / invalid_citation，不做补救性猜测
```

数据集：PubMedQA **PQA-L 1000 篇**（train 349 / dev 151 / test 500，按文献切分）。
v3 另建 **30 条新文献探索性验收集**（PQA-Artificial 池，机器标签分层抽样，与已用 1000 篇零交集）。

## 5. 通过核查定位的关键问题（项目的方法学产出）

1. **监督目标偏置**（v2 核查，代码级）：Task B 训练目标的 `Answerable` 用"是否命中正确文献"
   代替语义充分性（149/342=43.6% 的 yes 样本证据里没有结果段）；36.6% 的 Reason 目标是整段
   而非一句话。这解释了弃答行为与理由风格的来源，是 v2/v3 所有对照设计的出发点。
2. **"改监督目标"的小样本微调不可行**（v2 C-1，干预对照）：充分性监督把弃答率推到 94.7%。
3. **模型迁移的收益与代价**（v3）：27B 零样本在新文献全文证据上分类 24/29、弃答与证据
   不足判断一致（1/1、0/29）；但 dev151 上弃答率 39–45%（0.6B 微调后 ≈0.7%），
   且每条成本 5.7 s——**记录为收益与代价并存**，不宣称孰优。
4. **引用忠实度可机械核查的部分**：流程 B 的摘录 99.6% 可回溯（A1 修订后），
   但 B2 并不严格采纳 B1（24+7/151）——定位与判断的传导是开放问题。

## 6. 限制（全部如实登记）

- **探索性验收**：30 条验收集的参考标签含 7 条待裁决（预测后才裁决=程序偏差已登记），
  分数为**暂定**；输出评审为 AI 辅助，未经独立人工复核。
- **不足场景仅 1 条**（V16），无法充分评价弃答能力（M1 分母=1）。
- dev151/dev26 反复用于开发决策，**不是**独立验收集；验收集问题为机器生成。
- v3 仅在**给定上下文**上评测；**未接入检索管线**（见 `docs/V3_DEMO_CASES.md` §4 的集成登记）。
- 人工材料为工具辅助（Codex 盲评）与 AI 辅助（助手）记录，无独立第二审核者。
