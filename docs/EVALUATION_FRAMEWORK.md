# BioEvidence 统一评测框架（求职展示版）

**目的**：把项目里所有已计算的指标放进**同一套定义**下说明——每项指标写明定义、分子、分母、
invalid/N/A/未知处理、真值来源、审核方式、适用数据与限制。
**纪律**：不同协议的分数**不按高低排名**；每行结果标注模型、训练经历、证据形态与分母。
版本对照表由脚本从冻结产物自动生成（`portfolio/generate_portfolio_data.py`），
手写正文与自动数字用标记区分，避免手抄错列。

## 一、指标定义

### 1. 答案正确性（分类）
- **定义**：模型 `Label` 与该数据集参考标签（yes/no/maybe）的一致率。
- **分子/分母**：正确条数 / 参与分类的条数。
- **invalid/N/A/未知**：解析失败（invalid）计入分母且计为错误；格式失败单列；v3 验收集的
  `supported_label=N/A` 条目单列（不进分母）。
- **真值来源**：PubMedQA 官方 final_decision（v1 dev/test）；验收集为负责人填写稿（**暂定**）。
- **审核方式**：官方标签（未经本项目二次人工复核）；验收集 = 负责人人工填写（AI 辅助与否见来源）。
- **适用数据**：v1 dev151/test500（Task A 与 Task B 的 Label 字段）；v3 验收集（仅充分条目）。
- **限制**：类别不平衡（maybe 仅 ~11%）；不同证据条件下不可比。

### 2. 证据充分性（Answerable / 人工充分性）
- **定义（模型侧）**：模型 `Answerable=no` 表示"所给证据不足以回答"。
- **定义（参考侧）**：人工判 `evidence_sufficiency`（充分/不足/审核者无法判断）。
- **分子/分母**：见 §二各行的 M1/M2 行。
- **真值来源**：v1 训练目标 = **文献身份代理**（已知偏置，见 FAILURE_TAXONOMY F03）；
  v2 人工标注 64 条（单人）；v3 验收集 = 负责人填写稿（暂定，7 条待裁决）。
- **限制**：v1 的代理真值语义不自洽；人工标注单人、无第二审核者。

### 3. M1 无依据作答
- **定义**：人工判「证据不足」时模型却作答（Answerable=yes）。
- **分子/分母**：命中条数 / 人工判「不足」的条数。
- **invalid**：解析失败不计为"作答"，在有效弃答中计失败；单列。
- **真值来源**：dev26 = v2 人工充分性标注（14 条不足）；验收集 = 暂定参考（当前 1 条不足）。
- **限制**：验收集分母仅 1，**几乎无信息量**。

### 4. M2 错误弃答
- **定义**：人工判「充分」时模型却弃答（Answerable=no）。
- **分子/分母**：命中条数 / 人工判「充分」的条数。
- **invalid**：计失败（同上）。
- **限制**：依赖人工充分性判断的口径（含对问题缺陷的处理，如 V16）。

### 5. 证据支持理由（cited_supports_reason）
- **定义**：模型所引证据（Citations 指向的条目原文）是否支持**理由中的关键主张**。
  **不是**整个答案的正确性，**不是**最终标签正确性，**不构成**系统语义正确率。
- **取值**：支持 / 部分支持 / 不支持 / 无法判断 / N/A（无引用或弃答）。
- **分母**：作出回答的条数（弃答单列记 N/A）。
- **真值/审核**：AI 辅助评审（助手）与工具辅助盲评（Codex）各评过一部分；**均未经独立人工复核**。
- **限制**：语义判断，不可机械复算；"摘录可回溯"（逐字出现在证据中）是另一个更弱的机械量。

### 6. 理由支持标签（reason_supports_label）
- **定义**：Reason 的内容是否支持 Label 所示方向。
- **取值**：同上五级。
- **限制**：同 §5；弃答时按包内约定记 N/A。

### 7. 引用忠实度（citation_faithfulness）
- **定义**：模型对**所引证据**的使用是否忠实于该证据原文（有无转述失真、张冠李戴）；
  不要求逐字复述。
- **取值**：忠实 / 部分忠实 / 不忠实 / 无法判断 / N/A（无引用）。
- **分母口径（必须注明）**：主口径 = **排除弃答样本**（29 条适用输出：忠实 28、部分忠实 1）；
  含弃答合计 = 30 条（V16 弃答单列，其所引 E1/E3 单独核对为忠实）。两种口径不得混用。
- **区分**：「摘录可回溯」（流程 B 摘录逐字出现在证据中，机械可查 99.6%）是**更弱**的量，
  不等于语义忠实。

### 8. 错误作答 / 错误弃答（受控证据变化方向）
- **定义**：在证据条件对照下（保留支持信息 vs 移除支持信息），前者答错、后者未弃答。
- **状态**：**未评测**——当前仅 V16 一条不足样本；设计预案见 `docs/V3_NEXT_STEPS.md` 第三步。

### 9. 格式与契约
- **解析成功**：四行契约可被严格解析（30/30 = v3 验收集）。
- **完整契约通过**：解析成功且无契约违规（弃答引用非空 / Label 与 Answerable 矛盾 / 引用越界）。
  验收集 = **29/30**（V16 违规）。两项**必须分开报告**。
- **截断**：`finish_reason=length`，计格式失败、留在分母。

### 10. 运行成本
- **定义**：每条墙钟时间、生成 token 数、tokens/s（生成阶段，batch=1）。
- **限制**：本机桌面负载为混杂因素；不报告首 token 延迟（无流式测量）。

## 三、v3-P1 必须保留的口径约束（结项时负责人确认）

1. **暂定参考标签**：7 条待裁决项在预测生成时未裁决（程序偏差已登记），分类分数为**暂定**；
   后续裁决须注明发生在预测之后，不得追认为事前冻结。
2. **评审来源分立**：A/B 选择依据 = 工具辅助盲评（Codex）；输出支持性 = AI 辅助评审（助手）；
   两者均**未经独立人工复核**，不得合并称"独立人工验证"。
3. **不足样本仅 1 条**：弃答能力未被充分验证（M1 分母=1）。
4. **证据形态不可比**：新文献验收集使用全部 CONTEXTS（无检索），dev151 使用检索片段——
   验收集 0.8276 与 dev151 0.4040 **不可直接比较**。
5. **解析成功 ≠ 完整契约通过**：30/30 vs 29/30（V16 弃答引用非空）分别报告。
6. **弃答与引用忠实度分母**：主口径排除弃答样本（29 条）；弃答 V16 单列核对——两种口径不得混用。
7. **验收程序偏差**：参考判断裁决未在预测生成前完成，属已登记偏差，处理方式为
   保留预测 + 暂定分数 + 裁决时点登记（不重跑、不追认）。
